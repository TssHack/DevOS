# Contributing to DevOS

Thank you for your interest in contributing to DevOS!

## Development Workflow

1. **Fork** the repository
2. **Create** a feature branch
3. **Implement** your changes
4. **Test** your changes
5. **Submit** a Pull Request

## Code Style

- Follow existing code style
- Write clear commit messages
- Document your changes

## Pull Requests

- Keep PRs focused on a single feature
- Describe what and why, not just how
- Reference related issues

## Reporting Issues

- Use the issue template
- Include system information
- Provide reproduction steps

## Code of Conduct

Be respectful and constructive. We want DevOS to be a welcoming project for everyone.
