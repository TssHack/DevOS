# DevOS GRUB theme
#
# Source of truth for layout. Rendered into boot/grub/themes/devos/ by
# scripts/render-grub-theme.sh, which replaces @LOGO_*@ with the logo size.
# The content block (logo, menu, countdown) is ~690 px tall and vertically
# centred, so the layout holds from 1024x768 to 1920x1080 and beyond; the
# background is cropped, never stretched.
#
# GRUB draws a styled box's border pieces *outside* the area it wraps:
#   selected box height = item_height + 2 x 12 (select corner) = 58
#   item pitch          = item_height + item_spacing        = 58
#   menu height         = 7 items x 58 + 2 x 20 (menu corner) = 446 at 1080p
# Menu height and everything below it carry a small percentage term so the
# countdown and key hints still fit at 1280x720 (menu = 5%+392, 7 rows from
# 720p up; more entries scroll).
